# 交互细节

批注框写到一半不会丢，开在看得见的地方，上下边缘不会切过一行字，可以只用键盘走完批注。替换内容、删除版本都能从 Toast 撤销。左栏三个页签各自记住滚动位置、展开的条目和写到一半的字。缩放跟着窗口和左栏变化，用户自己选的缩放不会被改掉。弹窗、批注框和 Toast 有退出动画，减弱动效时仍保留状态反馈。左栏选填的个人情况和求职意向默认收起。窄窗口里两侧面板让出宽度。左栏条目按模块使用自己的字段名，简历上的技能行和经历要点带同样的圆点。左栏的要点像文档块一样编辑，两侧面板可以拖宽，批注卡片和页面上的图钉互相呼应，回车接受当前卡片的修改。

## Sub-features

- `draft` 换组件或按 Esc 后草稿按组件保留，组件旁有小红点，快捷词接在已写内容后面发送。
- `composer-fit` 格式栏默认收起，输入框随内容长高；靠近可视区底部时翻到目标上方，都放不下就滚动画布。
- `composer-edge` 批注框靠近目标的那条边落在两行字之间，不切过任何一行。左边缘和选中框的外沿对齐。分栏模板同样要求完整避开文字，检查失败会阻断发布。
- `reveal` 激活批注、点图钉、导出前定位时，目标不在可视区就滚到上部 30% 处。
- `field-reveal` 在简历上选中组件，左栏切回“内容”页，对应字段滚进视野，离面板边缘留 12px。
- `tab-memory` 内容、版式、版本三个页签切换时不卸载，各自保留滚动位置、展开的条目和写到一半的字。
- `keyboard` 简历是一个 Tab 位，上下方向键移动，回车打开批注框，Esc 或发送后焦点回到简历。键盘聚焦方案按钮也会预览。
- `toast-undo` 删除版本、恢复版本、新建空白、载入示例、从备份恢复，Toast 上都有撤销。换掉整份简历时，目标组件已不存在的批注会一起移除，撤销时一起回来；新建空白、载入示例、导入和从备份恢复还会收起「岗位匹配」卡片，恢复版本保留它。备份文件包含岗位匹配。
- `cancel` 用户取消 AI 后显示“已取消，可重试。”和重试按钮。
- `next` 接受或拒绝一条后，出现“下一条待处理 →”并获得焦点。点它后，刚决定的批注移到「已解决」，下一条展开。
- `entry-fields` 左栏展开的条目在标题行直接改名称，下面不再重复名称字段。工作是公司名称和职位，项目是项目名称和角色，教育是学校名称和专业，技能只有技能类别。折叠的技能条目显示它的内容。新条目输入第一个字后仍然展开，焦点留在名称框。
- `skill-dot` 技能行和经历要点用同一个圆点，书卷模板里是强调色。一个类别写了几行时，行与行之间留出间隔。分栏模板里居中的技能行，圆点仍在类别名旁边。
- `zoom` 缩放有三种来源。默认跟随版式，最多 80%，随窗口和左栏变化。点百分比在 100% 和适合宽度之间切换，适合宽度也随窗口变化。点缩小、放大，或 ⌘ 或 Ctrl 加滚轮、触控板捏合，得到一个固定值，之后窗口和左栏怎么变都不改它。
- `motion` 弹窗原地淡入，退出 140ms；提示气泡从触发点长出，相邻气泡不重播；减弱动效时转圈换成呼吸，红线换成 400ms 背景色。
- `touch` 没有悬停能力的设备上，排序和删除按钮常显。
- `optional-groups` 个人信息里的「个人情况」和「求职意向」默认收起成一行，分组名后面用灰字列出已填的值，没填时写“性别、出生年月、民族等，选填”。点这一行展开，两组各自独立。「联系方式」始终展开。
- `panel-width` 窗口变窄时两侧面板跟着变窄，左栏 272 到 312px，右栏 288 到 336px，按窗口宽的 22% 和 24%。1280 宽时默认缩放从 60% 变成 70%，1440 宽以上不变。CSS 的 `clamp()` 和 `App.tsx` 的 `panelsWidth` 是同一个公式，改一处要改另一处。
- `panel-resize` 拖左栏右边缘或批注栏左边缘改宽度（左栏 248 到 440px，批注栏 280 到 480px），页面的默认缩放跟着让出空间。宽度存在 `redline.panelWidths`，刷新后保留，双击边缘恢复默认。边缘可以 Tab 到，方向键每次 16px，按住 Shift 48px。
- `fold-slide` 点按钮收起或展开左栏时，栏宽用 160ms 滑动；⌘\ 立即折叠，不滑动。减弱动效时也不滑动。
- `block-bullets` 左栏的要点是连续的块：回车在光标处拆成两条，焦点到新的一条开头；行首退格把这一条并到上一条末尾；行首按 ↑、行尾按 ↓ 跨到相邻一条。「添加一条」仍保留。
- `accept-key` 当前展开的卡片上，接受按钮带 ↵。焦点在页面空白或卡片的非交互处时，回车接受这张卡片待处理的修改；焦点在输入框、按钮或简历上时，回车做它们自己的事。
- `card-pin` 指针停在一张批注卡片上，页面上它的图钉放大并加光圈，目标组件出现淡红细框。
- `roam-tag` 用方向键在简历上移动时，当前组件左上角贴一个组件名小标签；回车打开批注框后标签让给批注框的路径。鼠标选中不显示标签，因为它会盖住上一行字，批注框的路径已经写明了位置。
- `shockwave` 批注框打开后 40ms，一道红笔色的光晕从批注框靠近目标的那条边扫过中间画布，1 秒内扩到最远的角并淡出。四个色环由内到外是朱红、珊瑚、杏色、奶油，只给页面着色，不改颜色；经过的地方纸面像透镜一样弯几个像素，红蓝错开不到 1px，模块标题的横线和纸边微微发光。画布边缘 56px 内不弯。叠加层是 `.shockwave` WebGL2 画布，固定在画布可视区上，在纸面和桌面之上、图钉、预览胶囊和批注框之下，不接收指针，不打印，扫完就隐藏，不再请求动画帧。换一个组件打开批注框会重新开始；关掉批注框不会掐断正在扫的光晕。减弱动效时不弯、不闪，只在原地以一半强度 600ms 淡入淡出。弯曲用的页面快照由 `modern-screenshot` 在空闲时拍，内容、版式或缩放变化后等 1 秒、界面上没有动画时重拍；预览方案或减弱动效模式下不拍；系统动效偏好变化后重新判断。快照没拍好时这一次只着色、不弯曲。
- `type-levels` 左栏的模块标题（14px 中粗）大于其中的条目名（13px），分组标题（个人情况、求职意向）用墨色，和灰色的字段名分开。
- `tooltip` 提示气泡是暖石深色底 `--tip`、浅色字 `--tip-text`、中粗 500，对比度约 11:1，箭头和气泡同色。离窗口边缘至少 8px，被边缘推开时箭头仍对准按钮。轻按钮（工具栏、条目行、批注卡片上的图标）悬停时有半透明的暖色底，在已经变成 `--sunken` 的行和卡片上也看得出来。

## How to get to it (user POV)

- 点简历上的一句话写批注，再点别处或按 Esc。
- Tab 到简历，按 ↓ 和回车。
- 版本页删除一个版本，看底部 Toast。
- 点工具栏的缩放百分比，或按住 ⌘ 滚动画布。再拖窄窗口，看百分比跟不跟着变。
- 在“内容”页滚到底，展开一个条目，切到“版式”再切回来。

## Driving it with core-flow

Preconditions:

- 基线前提满足，已运行 `npm run build`。

- **草稿、定位、键盘、Toast 撤销、取消、下一条、缩放切换、动效、触屏。** 运行 `node e2e/interactions.mjs`，结尾是 `INTERACTIONS PASSED`。
- **批注框边缘、字段滚进视野、页签记忆、缩放跟随、阴影色调、条目字段名、技能圆点、提示气泡的边距、箭头、配色和字重、轻按钮悬停。** 运行 `node e2e/details.mjs`，结尾是 `DETAILS PASSED`。
- 测交付文件时两条都加 `REDLINE_HTML=Redline.html`。
- 新增检查做过变异测试：撤回对应修复后，脚本在对应检查处失败。`details.mjs` 的检查用 `scripts/mutate.mjs` 复跑。

## Gotchas

- 预览高亮的 `outline-color` 有过渡，读颜色前要等约 300ms。Chrome 在过渡中途用 `oklab()` 写颜色，`details.mjs` 里的 `rgba()` 会换算。
- 选中框是 1.5px 轮廓、3px 偏移，悬停是 1px 半透明。Chrome 会把 1.5px 按设备像素取整，1 倍屏上画成 1px，所以 `Canvas.tsx` 的 `ringReach()` 按 `devicePixelRatio` 算外沿。找选中的组件要比轮廓颜色是不透明的 `rgb(180, 53, 31)`，不要比宽度。
- Radix 提示气泡在指针越过上一个触发点之前不理会下一个。Playwright 的 `hover` 只发一次移动事件，测相邻气泡时要用 `mouse.move` 分步移动。
- 批注框仍会盖住目标下面几行，只是比以前少。测试里连续点两行时，第二行要离第一行远一些。
- 批注框有 160ms 的入场动画。量它的位置前等 `getAnimations()` 的 `finished`，几个浏览器并行时固定等待不够。
- 翻到目标上方只在短窗口里出现。`details.mjs` 用 1280×560、100% 缩放，点每个模板的最后几行。
- 默认缩放仍是最多 80%，所以第一次点百分比到 100%，第二次到适合宽度。适合宽度在 1440 宽时是 87%，1280 宽时是 74%（面板随窗口变窄之前是 67%）。
- 减弱动效和触屏要在新上下文里用 `reducedMotion: "reduce"`、`isMobile: true, hasTouch: true` 打开。
- 下面几处改代码时容易踩回去，`details.mjs` 都有检查守着。
  - 输入框加 Tailwind 的 `transition-colors` 后，聚焦时边框颜色会渐变，不再立即变墨色。
  - 只改 CSS 的面板宽度、不改 `panelsWidth`，缩放会按旧宽度算，页面变小但看起来没坏。`details.mjs` 量面板宽度和缩放两样。
  - 左栏折叠或展开后，程序把焦点交给切换按钮，Radix 提示气泡会因此打开。按钮上的 `data-quiet` 配合 `preventDefault` 拦住它。
  - Radix 的弹出层挂在 `body` 下，不隐藏就会打印进 PDF。`resume.css` 的打印样式把它们藏起来。
  - Chrome 的滚动时间线在切页签后保留旧进度，所以页签下的边线用 `[data-scrolled]` 属性，不用滚动时间线。
  - 阴影一律是暖石色 `rgba(28, 25, 23, …)`。shadcn 组件用 Tailwind v4 的 `shadow-xs`，它在 `ui.css` 里改成了暖色。照抄 v3 写法的 `shadow` 或 `shadow-sm` 会带回纯黑阴影。色板里的内描边也不能用 `rgba(0, 0, 0, …)`。
  - 名称为空的条目被强制展开。名称框的 `onChange` 先把条目加进展开集合，去掉这一步，输入第一个字条目就收起，焦点掉到 `body`。
  - 分栏侧栏的技能类别名不能设 `display: block`。居中后圆点会独占一行，类别名掉到下一行。
  - 轻按钮的悬停用 `--hover`。`--sunken`、`--line` 和 `--hover` 都是半透明的墨色，叠在任何底色上都看得出一层，`details.mjs` 量对比时先把行的半透明底叠到面板上再算。
  - 左栏折叠滑动时，收起的窄栏里切换按钮要靠左（`align-items: flex-start`）。居中的话，滑动的 160ms 里按钮会落在还没变窄的栏中间。
  - 提示气泡的箭头是 Radix 的 `Arrow`，挂在气泡内容里面。内容加 `overflow-hidden` 会把箭头裁掉。
- 分栏模板的侧栏与主栏文字会交错。批注框必须找到完整空隙；该示例最近空隙约 38.7px，`details.mjs` 要求不切字且距离小于 42px，失败即阻断发布。
- 光晕：
  - 透镜带里显示的是快照，快照里没有选中框。着色器按选中组件的位置把 1.5px 的选中框画回去（`ringAt`），悬停框和图钉不画，图钉本来就在叠加层之上。
  - 快照要按页面未缩放的尺寸拍（`width`、`height` 用 `offsetWidth`），只用 `scale` 放大。不传尺寸时 `modern-screenshot` 按缩放后的大小排版，透镜带里的字会放大错位。
  - 注入快照的样式要限定在 `[data-shot]` 里面。裸 `svg` 会命中包住快照的那个 `<svg>`，整张线条图变黑。
  - 纸面外只着色不弯曲。快照拍不到 `.page` 的外阴影，在桌面上输出快照会露出一块没有阴影的弧。
  - GLSL ES 3.0 里 `half` 是保留字。着色器编译失败时组件静默退回到不播放，`details.mjs` 读像素那一项会抓到。
  - WebGL 画布不保留绘制缓冲。`details.mjs` 在紧跟绘制的同一帧的 `requestAnimationFrame` 里 `toDataURL`，再数不透明像素（弯曲）和最大透明度（着色）。
  - Playwright 的 `clock.install()` 不会停住时间。要逐帧截图，先 `clock.pauseAt`，再 `runFor`。
  - 拍快照占主线程几十毫秒。拍之前检查 `document.getAnimations()`，有动画在跑就过 0.5 秒再试，否则会让左栏折叠的滑动掉帧，`details.mjs` 的滑动检查会误报。
- 没有在真实 iPad、Safari、Firefox 和读屏软件上验证。
