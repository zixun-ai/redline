# Redline 验证地图

这里是 Redline 面向用户行为的验证来源。驱动应用前先读本页，再按对应特性文件操作。

## 基线前提

- `node .claude/skills/verify-redline/scripts/doctor.mjs` 输出 `DOCTOR OK`。
- `dist/index.html` 由当前源码构建。
- 每条旅程从全新的浏览器上下文开始，页面显示示例简历（林知远），没有保存的 Key。Key 默认只在当前页内存中使用；测试需要刷新后继续请求时，要明确勾选“记住 API Key”。

## 驱动约定

- 优先用 ARIA 角色和可访问名称。工具栏的撤销和重做限定在 `.tools` 内，因为方案卡片上也有“撤销”按钮。
- 简历组件在 `.page-live` 内。`.item-head` 是条目标题行，`.composer` 是批注输入框，`.proposal` 是方案卡片。
- 段落模块（比如末尾的个人总结）在页面上是 `.sec` 里的 `.passage`，没有 `.item`。左栏里它只有一个文本框，新建按钮是 `.add-section` 里的“个人总结”。
- 版式页签的模板缩略图是 SVG 骨架（`.thumb svg`），不含简历文字和 `[data-node]`。导入核对弹窗里还有一份内容表单，所以定位简历元素仍然一律带上 `.page-live`。
- 左栏三个表单一直挂载，切页签只切换 `hidden` 属性。定位当前表单用 `.panel.left .form:not([hidden])`。
- 点击简历上的组件后，左栏会切回“内容”页。之后要用“版本”页时，先重新点“版本”。
- 用真实鼠标点击“接受”。悬停卡片产生的预览是用户路径的一部分。
- 界面用 shadcn/ui。左右栏的页签是 `role=tab`，分段选择是 `role=radio`，复选框是 `role=checkbox`，读状态用 `aria-checked` 或 `data-state`。
- 弹窗和提示挂在 `body` 下，不在触发它的面板里，定位时不要限定在面板内。
- 方向键切页签时焦点在定时器里才移动，先等焦点到位再断言。
- 格式栏默认收起，点批注框里的“展开格式”（T 图标）才出现，展开状态存在 `redline.formatOpen`。
- 批注框标题是路径 `.crumbs`，没有“选中上一级”按钮。点路径里的上一级就选中它。
- 批注框、弹窗、Toast 关闭后还会留 120 到 160ms 做退出动画。断言“已关闭”要等元素 `detached`，不要立即数个数。
- 等某个元素的动画播完，用 `el.getAnimations()` 的 `finished`。不要把 `document.getAnimations()` 全部拨到结尾，无限循环和滚动驱动的动画也在里面。
- 右栏的 `.sr-only` 也会播报 AI 结果，按文字找失败消息时限定在 `.msg .fail`。
- 右栏有「批注」和「已解决」两个页签。「批注」列出未解决的批注，再加上刚决定完、还留在原处的那一条。已解决卡片的编号位置是 `.num.done`。
- 左栏展开的条目，名称就是标题行里的 `.entry-title` 输入框，下面没有单独的名称字段。展开后切换按钮只剩箭头，可访问名称是条目名称。字段名随模块变化，教育是“学校名称、专业、时间”，技能只有“技能类别”。
- `hasText` 匹配不到输入框里的值，模块标题和条目名称都是输入框。找条目用 `[data-form]`，找模块用 `.group` 的序号。
- 焦点环只在没有指针历史的页面上误报，这类检查要开新页面。比较环的宽度，不比较 `box-shadow` 字符串。

## 证明与跳过

- 同时记录操作后的界面和 IndexedDB 中简历、批注等状态的只读核对。旧版 `redline.doc.v1`、`redline.threads.v1` 只用于迁移验证，不能作为新版保存结果。
- 汇报里写明旅程 ID 和证据目录。
- 走不通的路径写明命令和未满足的前提，不要用另一条路径代替。
